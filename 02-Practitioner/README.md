## Regla de trabajo

Para cada lab Practitioner:

```text
teoría oficial
→ entender el objetivo
→ guía del lab en GitHub
→ Burp paso a paso
→ resolver
→ explicar por qué funcionó
→ marcar progreso
```

No se trata de memorizar cadenas. Debemos saber:

- qué input es controlable;
- en qué contexto SQL entra;
- qué hipótesis estamos probando;
- qué señal confirma la hipótesis;
- qué herramienta de Burp conviene usar;
- cómo pasar de detección a impacto.
